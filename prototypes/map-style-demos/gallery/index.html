Map Style Trials

Three candidate looks for the Game UI world map (Travel & Map GDD, Visual/Audio). Each style has six seeded sets (three in round 1, three more in round 2), and every set draws the same three hand-authored maps from one shared data file, so you can compare like with like. Choose a map below; click any image to see it full size.

Pixel tiles điểm ảnh

16 × 16 tiles on the GDD's grid: one tile per cell, auto-tiled roads and rivers, place icons on top. Closest to Dwarf Fortress; the grid is the art.

Look up: Dwarf Fortress (Steam tiles), Caves of Qud, Amazing Cultivation Simulator

Hand-authored with the pxl and vex art skills. Source and rebuild steps: prototypes/map-style-demos/README.md. Every map is the GDD grid (28 × 18 cells); the parchment and ink styles draw that grid as contours and brush marks instead of squares.
