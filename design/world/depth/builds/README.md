# Build wishlists (world-depth pass)

User, 2026-11-25: "if something in the builds needs some specific effects, some new modifiers that we don't have,
write that effect down. We could still author them."

User, later the same day: "if a build theme or the build itself needs some more techniques, arts, wards, please feel
free to add it to the suggestion list. Or anything, not just these, anything to make the build working or fun."

So the wishlist covers **anything a build needs to work or to be fun**:
- Modifiers and Effects;
- techniques (a lineage's missing secret art, a body method, an outer-gate method that doesn't fit);
- arts (a missing art that would complete a suite or a stance);
- wards and shields;
- items, set bonuses and item bases;
- Đạo Đồ pieces (a notable, a small idea, a keystone, a border piece);
- talismans, formations, spirit beasts;
- an engine (two pieces that feed each other);
- a fight-feel idea (a stance, a combo, a counter, a way to win that isn't just bigger numbers).

Each build writer keeps `wishlist-<batch>.md` here (one file per writer, so no collisions). An entry:

- **Name** (English (Hán-Việt))
- **Kind**: Modifier, Effect, Technique, Art, Ward, Item, Đạo Đồ piece, or Other (say what). For the first two:
  - **Modifier**: a plain number on a stat, `+X` or `X % increased/more`, optionally tag-scoped, and conversion is
    allowed. Give the stat key, whether it is new, and the scope.
  - **Effect**: anything with a rule (condition, trigger, scaling, rule change). Effects are hand-designed and unpriced.
- **Rule or line**: one or two sentences, concrete enough to author.
- **Where it would live**: Đạo Đồ notable or keystone, item, technique (sect lineage), set bonus, or anything else.
- **Fun**: optional. What it makes the build do that feels good in a fight: the moment it creates.
- **Who needs it**: person keys and their sect.
- **Why**: what existing piece comes closest, and why it isn't enough.

Write it down rather than bending a build to fit. The wishlists are proposals for the user's review. Nothing is added
to `effects.md`, the Modifier System, or the tree.
