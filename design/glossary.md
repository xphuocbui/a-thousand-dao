# Glossary: English ↔ Hán-Việt

Design docs are written in English. The Vietnamese Hán-Việt term follows in parentheses
on its first use in a document or section, e.g. *sect (tông môn)*. Later mentions use the
English term only. Data keys, code identifiers and file names do not change.

The game's own player-facing text (debug terminal, data names) is still Vietnamese-first.
It will be revisited with Localization & Hán-Việt Glossary (system 34).

Craft skill levels are written "talisman skill level", "formation skill level", "Beast
Taming level" (Phù lục, Trận Pháp, Ngự thú).

System names (systems index): Spiritual Roots (Linh Căn), Realms & Bottlenecks (Cảnh Giới
& Bình Cảnh), Cultivation Techniques (Công Pháp), Meridian Map (Kinh Mạch Đồ), Spirit
Herbs & Spirit Fields (Linh Thảo & Linh Điền), Alchemy (Luyện Đan), Artifact Refining
(Luyện Khí), Formations (Trận Pháp), Talismans (Phù Lục), Spirit Beasts & Spirit Insects
(Linh Thú & Linh Trùng), Market & Spirit Stone Economy, Heavenly Tribulation (Thiên Kiếp),
Achievements (Thành Tựu).

Realm abbreviations in tables: QR = Qi Refining (Luyện Khí), FE = Foundation Establishment
(Trúc Cơ), CF = Core Formation (Kết Đan), NS = Nascent Soul (Nguyên Anh), DT = Deity
Transformation (Hóa Thần); early / mid / late / GP = sơ / trung / hậu kỳ / đại viên mãn.
